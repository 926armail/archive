# Поиск папки в архиве

Статическая страница: пользователь выбирает организацию, вид документов, год и месяц и получает адрес папки (шкаф, полка, папка). Одна и та же страница работает как сайт и как мини-приложение Telegram.

## Состав

| Файл | Назначение |
|---|---|
| `index.html`, `style.css`, `app.js` | Сама страница, менять не нужно |
| `config.js` | Откуда брать реестр |
| `data.csv` | Реестр, если работаете через Excel |

## Источник данных

Реестр должен содержать колонки (порядок любой, ищутся по словам в заголовке):
`Номер шкафа`, `Номер полки`, `Номер папки`, `Наименование организации`, `Вид документов`, `Период документов`.

Период пишется текстом, как сейчас: «Июль — август 2018», «Апрель 2019», «2017–2022», «I квартал 2021», «1 полугодие 2023», «Апрель 2021 — март 2022».

### Вариант А — Google Таблица (рекомендуется)
1. Загрузите Excel в Google Диск → «Открыть в Google Таблицах».
2. Файл → Поделиться → Опубликовать в интернете → выбрать лист реестра → формат «CSV» → Опубликовать.
3. Скопируйте ссылку в `config.js` → `SHEET_CSV_URL: "ссылка"`.
4. Дальше реестр правится прямо в таблице, сайт подхватывает изменения сам (Google обновляет опубликованную версию в течение нескольких минут).

### Вариант Б — Excel
1. Excel → Сохранить как → «CSV UTF-8 (разделитель — запятая)» → имя `data.csv`. Разделитель «;» тоже поддерживается.
2. Загрузите файл в репозиторий с заменой старого (Add file → Upload files).

Важно: колонка «Номер папки» должна быть в текстовом формате, иначе Excel превратит 4.10 в 4.1.

## Публикация на GitHub Pages
1. github.com → New repository → имя, например `archive` → Public → Create.
2. Add file → Upload files → перетащите все файлы из этой папки → Commit.
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/archive/`.

## Мини-приложение в Telegram
1. В Telegram откройте @BotFather → `/newbot` → задайте имя → получите бота.
2. `/mybots` → ваш бот → Bot Settings → Menu Button → укажите ссылку на сайт из GitHub Pages и подпись, например «Найти папку».
3. Готово: в боте появится кнопка, которая открывает поиск внутри Telegram. Цвета подстраиваются под тему Telegram.

Сервер и токен бота для этого не нужны: бот только показывает кнопку.
Для удобства можно также через BotFather создать Mini App (`/newapp`), тогда у приложения будет своя ссылка вида `t.me/<бот>/<имя>`.
